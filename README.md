# 🎮 GameHub - A Game Library

**GameHub** is an engaging online library for discovering and supporting game developers. Users can browse indie games, view detailed information about each game, and install them if they like.

---

## 🌐 Live Demo
🔗 [https://my-assignment-nine-4baaa.web.app/](https://my-assignment-nine-4baaa.web.app/)

---

## ✨ Key Features

- 🏠 **Homepage** – Browse featured games  
- 🎮 **Game Details Page** – Protected, shows detailed info  
- 🔐 **Authentication**  
  - Login Page  
  - Register Page  
  - Forgot Password  
- 🧭 **Navbar / Header** – Navigation for all pages  
- 👤 **User Profile** – Update personal information  
- 📄 **Additional Pages** – Error page with error IDs  

---

## 🛠️ Technologies & Packages Used

- **Frontend**: React, Tailwind CSS, DaisyUI  
- **Routing & UI**: React Router, React Icons, React Slick, Slick Carousel  
- **State & Notifications**: React Toastify  
- **Backend / Auth**: Firebase Authentication  
- **SEO & Meta**: React Helmet  
- **Others**: @tailwindcss
